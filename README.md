# bomba-live

The Overlook / Bomba Live web page. Open it on any computer, phone or tablet,
enter your wall code, and watch every shared screen at once. Computers can also
share their screen from the Share tab.

- `index.html` — the whole page in one file (nothing else needed)
- `live.html` — the same page, using `peerjs.min.js` and `bomba-wall.js`
- `bomba-wall.js` — shared with Orbit, BombaArgus and OverLook (see CONNECTING.md)
